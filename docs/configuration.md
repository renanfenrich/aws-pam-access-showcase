# Configuration

Terraform inputs are documented in `terraform/environments/showcase/variables.tf`. The safety defaults are intentionally unusable for deployment: `deployment_enabled=false`, empty operator CIDR, empty authorization expiration, and empty expiration tag.

`scripts/ensure_secrets.py` fills an empty Secrets Manager container only when it has no current value. It creates JumpServer encryption/token/admin/demo/database/Redis values, the dedicated target SSH key, OpenVPN CA/server/client material and profile, and the JumpServer private TLS CA. It prints only secret logical names and counts.

The generated Ansible inventory contains instance IDs, networking facts, and secret container names—not secret values. The controller retrieves values under `no_log`; the JumpServer API client retrieves the minimum values through the instance role and emits a sanitized result.

The API client is pinned to JumpServer `v4.10.18`. Before mutation it downloads the deployed `/api/swagger.json` generated by `/api/docs/` and fails if any expected route is absent. The routes and serializer payloads were derived from the tagged upstream source, not guessed.
